# LifeOS REST API Specification

This document lists all the REST endpoints exposed by the LifeOS backend.

---

## Authentication & Authorization Rules

- **Public Endpoints**: Endpoints under `/api/auth/**` (such as registration and login) do not require credentials.
- **Protected Endpoints**: All other endpoints (prefixed with `/api/` or `/users/`) require a valid JSON Web Token (JWT) sent in the HTTP headers:
  `Authorization: Bearer <jwt-token>`

---

## 1. Authentication Domain (`/api/auth`)

### Register User
* **Method**: `POST`
* **Route**: `/api/auth/register`
* **Authentication**: Public
* **Description**: Create a new user account.
* **Request Body**:
  ```json
  {
    "email": "student@college.edu",
    "password": "strongPassword123"
  }
  ```
* **Response** (200 OK):
  ```json
  {
    "token": "eyJhbGciOi...",
    "user": {
      "id": 1,
      "email": "student@college.edu"
    }
  }
  ```

### Login User
* **Method**: `POST`
* **Route**: `/api/auth/login`
* **Authentication**: Public
* **Description**: Log in with credentials and obtain a JWT.
* **Request Body**:
  ```json
  {
    "email": "student@college.edu",
    "password": "strongPassword123"
  }
  ```
* **Response** (200 OK):
  ```json
  {
    "token": "eyJhbGciOi...",
    "user": {
      "id": 1,
      "email": "student@college.edu"
    }
  }
  ```

### OAuth Code Exchange
* **Method**: `POST`
* **Route**: `/api/auth/oauth/exchange`
* **Authentication**: Public
* **Description**: Consume a temporary code generated by the Google OAuth success handler and issue a JWT.
* **Request Body**:
  ```json
  {
    "code": "temporary_exchange_code"
  }
  ```
* **Response** (200 OK):
  ```json
  {
    "token": "eyJhbGciOi..."
  }
  ```

## 2. Tasks Domain (`/api/task`)

### Create Task
* **Method**: `POST`
* **Route**: `/api/task`
* **Authentication**: Required JWT
* **Description**: Create a task.
* **Request Body**:
  ```json
  {
    "title": "Solve homework assignment",
    "description": "Chapters 1 to 3 problems",
    "dueDate": "2026-08-10T12:00:00",
    "priority": "HIGH",
    "status": "TODO",
    "labelId": 2,
    "taskType": "ACADEMIC"
  }
  ```
* **Response** (200 OK): Created Task details.

### Get All Tasks
* **Method**: `GET`
* **Route**: `/api/task/all`
* **Authentication**: Required JWT
* **Description**: Fetch all tasks owned by the authenticated user.
* **Response** (200 OK): List of Task objects.

### Get Task by ID
* **Method**: `GET`
* **Route**: `/api/task/{taskId}`
* **Authentication**: Required JWT
* **Description**: Fetch task details by path parameter ID.
* **Response** (200 OK): `TaskDetailView` object.

### Update Task Status
* **Method**: `PUT`
* **Route**: `/api/task/{taskId}/{status}`
* **Authentication**: Required JWT
* **Description**: Update the status of a specific task.
* **Parameters**:
  - `taskId`: Long (path)
  - `status`: String (path, e.g. `TODO`, `IN_PROGRESS`, `DONE`)
* **Response** (200 OK): Updated Task object.

### Update Task Details
* **Method**: `PUT`
* **Route**: `/api/task/{taskId}`
* **Authentication**: Required JWT
* **Description**: Modify multiple details of an existing task.
* **Request Body**: `TaskUpdateDto` object containing updated fields.
* **Response** (200 OK): Updated Task object.

### Search and Filter Tasks
* **Method**: `GET`
* **Route**: `/api/task`
* **Authentication**: Required JWT
* **Description**: Fetch tasks with optional filters.
* **Query Parameters**:
  - `status`: String (optional)
  - `labelId`: Long (optional)
  - `taskType`: String (optional)
* **Response** (200 OK): List of filtered Task objects.

### Get Upcoming Tasks
* **Method**: `GET`
* **Route**: `/api/task/upcoming`
* **Authentication**: Required JWT
* **Description**: Fetch upcoming tasks sorted chronologically.
* **Response** (200 OK): List of `UpcomingTaskDto` tasks.

### Get Task Statistics
* **Method**: `GET`
* **Route**: `/api/task/stats`
* **Authentication**: Required JWT
* **Description**: Fetch a count summary of tasks grouped by status (todo, in progress, done, overdue).
* **Response** (200 OK):
  ```json
  {
    "totalTasks": 25,
    "completedTasks": 15,
    "pendingTasks": 8,
    "overdueTasks": 2
  }
  ```

### Delete Task
* **Method**: `DELETE`
* **Route**: `/api/task`
* **Authentication**: Required JWT
* **Description**: Delete a task by ID.
* **Query Parameters**:
  - `taskId`: Long (required)
* **Response** (200 OK): Success confirmation.

## 3. Prioritization & AI Domain

### Get Prioritized Tasks
* **Method**: `GET`
* **Route**: `/api/tasks/prioritized`
* **Authentication**: Required JWT
* **Description**: Retrieve active tasks sorted by computed priority scores.
* **Response** (200 OK):
  ```json
  [
    {
      "id": 12,
      "title": "Study for midterm exam",
      "score": 85.5,
      "priorityLevel": "CRITICAL",
      "reasons": [
        "Task is due within 24 hours (+50 points)",
        "Task weight label 'Academics' carries heavy rank (+30 points)",
        "Priority is explicitly configured as HIGH (+5 points)"
      ]
    }
  ]
  ```

### Generate AI Task Draft
* **Method**: `POST`
* **Route**: `/api/task-generation`
* **Authentication**: Required JWT
* **Description**: Use Gemini AI to generate a structured task outline draft from raw description strings.
* **Request Body**:
  ```json
  {
    "prompt": "Prepare for chemistry lab tomorrow doing titration experiments"
  }
  ```
* **Response** (200 OK):
  ```json
  {
    "title": "Prepare Chemistry Titration Lab Notes",
    "description": "Read lab manual chapter 4, review titration equations, and set up lab journal layout.",
    "taskType": "ACADEMIC",
    "suggestedLabels": ["Chemistry", "Lab"],
    "suggestedPriority": "HIGH"
  }
  ```

## 4. Labels Domain (`/api/labels`)

### Create Label
* **Method**: `POST`
* **Route**: `/api/labels`
* **Authentication**: Required JWT
* **Description**: Create a custom user-owned focus label.
* **Request Body**:
  ```json
  {
    "name": "Math Homework",
    "weight": 8
  }
  ```
* **Response** (200 OK): Created Label details.

### Get Labels
* **Method**: `GET`
* **Route**: `/api/labels`
* **Authentication**: Required JWT
* **Description**: Fetch all focus labels created by the current user.
* **Response** (200 OK): List of Label objects.

### Update Label
* **Method**: `PUT`
* **Route**: `/api/labels/{labelId}`
* **Authentication**: Required JWT
* **Description**: Modify label name or importance weight.
* **Request Body**:
  ```json
  {
    "name": "Calculus",
    "weight": 10
  }
  ```
* **Response** (200 OK): Updated Label details.

### Delete Label
* **Method**: `DELETE`
* **Route**: `/api/labels/{labelId}`
* **Authentication**: Required JWT
* **Description**: Delete a label.
* **Response** (200 OK): Status confirmation.

### Seed Default Labels
* **Method**: `POST`
* **Route**: `/api/labels/defaults`
* **Authentication**: Required JWT
* **Description**: Seed default academic labels (e.g. Exam, Homework, Project) for new profiles.
* **Response** (200 OK): `"Default labels successfully seeded"`

## 5. Notes Domain (`/api/notes`)

### Create Note
* **Method**: `POST`
* **Route**: `/api/notes`
* **Authentication**: Required JWT
* **Description**: Create a study note, optionally attaching it to a task.
* **Request Body**:
  ```json
  {
    "title": "React Hooks Notes",
    "content": "Use useEffect to perform side-effects in functional components.",
    "taskId": 4
  }
  ```
* **Response** (201 Created): `NoteView` object.

### Get Note by ID
* **Method**: `GET`
* **Route**: `/api/notes/{noteId}`
* **Authentication**: Required JWT
* **Description**: Retrieve a specific note.
* **Response** (200 OK): `NoteView` details.

### Get All Notes
* **Method**: `GET`
* **Route**: `/api/notes`
* **Authentication**: Required JWT
* **Description**: Fetch all notes of the authenticated user.
* **Response** (200 OK): List of `NoteListView` notes.

### Get Notes by Task
* **Method**: `GET`
* **Route**: `/api/notes/task/{taskId}` (also routes `/api/notes/tasks/{taskId}/notes`)
* **Authentication**: Required JWT
* **Description**: Retrieve notes linked to a task.
* **Response** (200 OK): List of `NoteListView` notes.

### Update Note
* **Method**: `PUT`
* **Route**: `/api/notes`
* **Authentication**: Required JWT
* **Description**: Update note details.
* **Request Body**:
  ```json
  {
    "id": 8,
    "title": "React Hooks",
    "content": "React hooks let you use state without writing a class.",
    "taskId": 4
  }
  ```
* **Response** (200 OK): Updated `NoteView` details.

### Delete Note
* **Method**: `DELETE`
* **Route**: `/api/notes/{noteId}`
* **Authentication**: Required JWT
* **Description**: Delete a note.
* **Response** (204 No Content)

## 6. Social & Friends Domain

### Send Friend Request
* **Method**: `POST`
* **Route**: `/api/friends/request/{receiverId}`
* **Authentication**: Required JWT
* **Description**: Send a friend request.
* **Response** (200 OK): Status confirmation.

### Accept Friend Request
* **Method**: `POST`
* **Route**: `/api/friends/request/{requestId}/accept`
* **Authentication**: Required JWT
* **Description**: Accept a pending request.
* **Response** (200 OK): Status confirmation.

### Reject Friend Request
* **Method**: `POST`
* **Route**: `/api/friends/request/{requestId}/reject`
* **Authentication**: Required JWT
* **Description**: Reject a pending request.
* **Response** (200 OK): Status confirmation.

### Get Friends List
* **Method**: `GET`
* **Route**: `/api/friends`
* **Authentication**: Required JWT
* **Description**: Fetch all friends.
* **Response** (200 OK): List of Student Profile views.

### Remove Friend
* **Method**: `DELETE`
* **Route**: `/api/friends/{friendId}`
* **Authentication**: Required JWT
* **Description**: Break friendship connection.
* **Response** (200 OK): Status confirmation.

### Get Pending Friend Requests
* **Method**: `GET`
* **Route**: `/api/friends/requests/incoming` (for incoming requests) or `/api/friends/requests/outgoing` (for outgoing requests)
* **Authentication**: Required JWT
* **Description**: Fetch pending incoming or outgoing requests.
* **Response** (200 OK): List of request payloads.

### Get Friend Activity Feed
* **Method**: `GET`
* **Route**: `/api/social/feed`
* **Authentication**: Required JWT
* **Description**: Fetch social activities feed containing updates from friends (streaks, leveling up, completed tasks).
* **Response** (200 OK): List of `FriendActivityResponse` objects.

## 7. Profile, Dashboard, & Stats Domain

### Get Student Profile
* **Method**: `GET`
* **Route**: `/api/profile`
* **Authentication**: Required JWT
* **Description**: Retrieve the current user's profile.
* **Response** (200 OK): `StudentProfileView` details.

### Create Student Profile
* **Method**: `POST`
* **Route**: `/api/profile`
* **Authentication**: Required JWT
* **Description**: Create student profile details.
* **Request Body**: `StudentDto` details (college, bio, branch, major).
* **Response** (200 OK): Created profile details.

### Get Dashboard Aggregation
* **Method**: `GET`
* **Route**: `/api/dashboard`
* **Authentication**: Required JWT
* **Description**: Fetch unified payload summarizing current user status.
* **Response** (200 OK):
  ```json
  {
    "profile": { "name": "Alex", "college": "MIT" },
    "streak": 5,
    "stats": { "points": 1250, "completedTasks": 15 },
    "prioritizedTasks": [...],
    "upcomingTasks": [...],
    "recentActivity": [...]
  }
  ```

### Get Insights Data
* **Method**: `GET`
* **Route**: `/api/insights`
* **Authentication**: Required JWT
* **Description**: Fetch user productivity insights (weekly completion trend, task heatmap, focus distribution).
* **Response** (200 OK): `InsightsResponse` details.

### Get Leaderboard Rankings
* **Method**: `GET`
* **Route**: `/api/leaderboard`
* **Authentication**: Required JWT
* **Description**: Get sorted leaderboard entries.
* **Query Parameters**:
  - `scope`: String (required, `GLOBAL`, `FRIENDS`, or `COLLEGE`)
* **Response** (200 OK): List of `LeaderboardEntryDto` objects.

### Get Levels Info
* **Method**: `GET`
* **Route**: `/api/levels/me`
* **Authentication**: Required JWT
* **Description**: Get the level milestone progression statistics for the authenticated user.
* **Response** (200 OK): `UserLevelResponse` details.

### Get Profile Stats
* **Method**: `GET`
* **Route**: `/api/stats/me`
* **Authentication**: Required JWT
* **Description**: Get points, streaks, level, and completed tasks counter statistics.
* **Response** (200 OK): `UserStatsDto`.

### Rebuild Profile Stats
* **Method**: `POST`
* **Route**: `/api/stats/rebuild/me`
* **Authentication**: Required JWT
* **Description**: Rebuild points and streaks stats.
* **Response** (200 OK): None.

* **Authentication**: Required JWT
* **Description**: Get user account details.

* **Method**: `PUT`
* **Route**: `/users`

### Delete User Account
* **Method**: `DELETE`
* **Route**: `/users`
* **Authentication**: Required JWT
* **Description**: Delete the current user account.
* **Response** (200 OK)

### Get Academic Branches
* **Method**: `GET`
* **Route**: `/api/branch`
* **Authentication**: Required JWT
* **Description**: Retrieve list of academic departments/branches.
* **Response** (200 OK): List of Branch objects.
